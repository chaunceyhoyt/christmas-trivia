# Sound slots

Drop MP3 files in this folder with these **exact** names. The big screen uses a file when it's here and a built-in synthesized sound when it isn't, so you can add them one at a time. Reload the big screen after adding files.

| File | When it plays | Ideas |
| --- | --- | --- |
| `join.mp3` | A player joins | Single sleigh bell shake, "Ho ho ho" |
| `round_intro.mp3` | A round's title card | Sleigh bells + fanfare |
| `question.mp3` | Each question appears | One church bell / chime |
| `golden.mp3` | Golden ornament (double points) question | Magic sparkle, harp gliss |
| `tick.mp3` | Each of the last 5 seconds | Clock tick (keep it very short) |
| `timeup.mp3` | Time runs out | Bicycle bell, low bell |
| `land.mp3` | Avatars drop onto answers | Snow crunch, soft plops |
| `correct.mp3` | Answer is revealed | Handbells, "ding ding ding" |
| `streak.mp3` | Someone hits a snowball streak (3 right in a row) | Ascending bells |
| `silly.mp3` | Kid "Jingle Jiggle" break | Boing, kazoo, slide whistle |
| `round_end.mp3` | Round is over | Jingle bells outro, "Merry Christmas!" |
| `alarm.mp3` | Any surprise round (fallback for all of them) | Siren, air horn |
| `alarm_rudolph.mp3` … | One surprise round. Also: `alarm_grinch`, `alarm_homealone`, `alarm_griswold`, `alarm_snowday`, `alarm_turbo`, `alarm_nightmare`, `alarm_diehard` | Siren + a themed sound |
| `music_lobby.mp3` | Loops quietly in the lobby, between rounds and when paused | Instrumental Christmas jazz |
| `music_think.mp3` | Loops quietly while people answer (not during music/sound/video questions) | Gentle music box loop |

Free sources with licenses that allow this: [Pixabay sound effects](https://pixabay.com/sound-effects/search/christmas/) and [Pixabay music](https://pixabay.com/music/search/christmas/) (no attribution needed), [Freesound](https://freesound.org) (filter by the CC0 license). Keep effects short (under 3 seconds) and trim silence off the start so they land on time.

# Media rounds

Put pictures, sound clips and video clips here with the **exact** file names listed below. A question whose file is missing is skipped. A round with no files at all is greyed out on the host controller. Reload the big screen after adding files.

**Up to 3 versions of each file:** add `_1`, `_2` or `_3` before the extension, like `elf_1.png`, `elf_2.png`, `elf_3.png` (or `clip-elf_1.mp4`). Each time the question comes up, the game plays one of them at random. Any one, two or all three can be there; the plain name (`elf.png`) works too when there's just one.

These are for your own party at home. Use clips you have the right to use (for example, ones you recorded yourself from movies you own).

## The Frame Game (pictures, PNG)
A still from each movie. It starts blurry (or zoomed in) and clears up as time runs out.
`home-alone.png`, `elf.png`, `a-christmas-story.png`, `christmas-vacation.png`, `die-hard.png`, `grinch.png`, `polar-express.png`, `nightmare-before-christmas.png`, `muppet-christmas-carol.png`, `santa-clause.png`, `gremlins.png`, `love-actually.png`, `its-a-wonderful-life.png`, `miracle-on-34th-street.png`, `white-christmas.png`, `scrooged.png`, `jingle-all-the-way.png`, `bad-santa.png`, `krampus.png`, `the-holiday.png`, `trading-places.png`, `batman-returns.png`, `home-alone-2.png`, `fred-claus.png`

About 1920×1080 is ideal (sizes can vary a bit). PNG is expected; a JPG with the same name (like `elf.jpg`) also works. Keep each under about 2 MB so it loads quickly. Avoid frames with the title or other on-screen text.

## Clip Show (MP4)
A few seconds of video from each movie. Keep files small (under 10 MB, 720p is plenty).
`clip-home-alone.mp4`, `clip-elf.mp4`, `clip-a-christmas-story.mp4`, `clip-christmas-vacation.mp4`, `clip-die-hard.mp4`, `clip-grinch.mp4`, `clip-polar-express.mp4`, `clip-muppet-christmas-carol.mp4`

To add your own questions or change names, edit the media rounds near the bottom of `assets/questions.js`. A video can play just part of a file: `{video:"assets/media/x.mp4", start:12, end:20}`.
